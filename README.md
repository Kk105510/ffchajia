# 艾欧泽亚物价雷达 · FF14 国服查价网站

一个专门为《最终幻想 XIV》中国服设计的响应式网页，风格参考用户提供的市场行情图。**仅需 HTML / CSS / JS，无需安装环境、API 密钥或后台服务器。**

## iPhone 特别注意（重要）

**请不要直接在 ChatGPT 附件预览、iPhone「文件」或 Quick Look 中测试 HTML 网页。**
这些预览界面可能只渲染静态 HTML/CSS 而不执行 JS，因此：
搜索、夜间模式、图表交互都不会响应。这不等于市场 API 故障。

推荐：将本 ZIP 解压，并上传到 GitHub 仓库，再启用 GitHub Pages。
部署完成后，**复制 Pages 提供的 HTTPS 地址，粘贴到 Safari/Chrome 地址栏打开**。
第一次打开若出现黄色「网页交互尚未启动」提示，说明当前环境尚未执行 JS，应该检查是否真的在浏览器中打开、文件是否部署完整。

v3 修正：默认不自动打开物品；页面新增脚本状态诊断、缓存版本标记、文件路径错误保护；搜索和夜间模式初始化调整。单文件版与 ZIP 版同步。

## 包含哪些功能

- 中文物品名搜索、英文物品名搜索、物品数字 ID 直查；优先使用 XIVAPI 中文镜像，失败后尝试 FFCafe。
- 中国国服四个大区：陆行鸟、莫古力、猫小胖、豆豆柴，以及「中国全区」跨区对比。
- 全品质 / NQ / HQ 筛选。
- 最低挂单价、挂单中位价（P25/P50/P75）、当前挂单数、近 30 天已上传的日均成交件数。
- 每个世界服的最低价 / 中位价 / 挂单分布 / 挂单数 / 成交与更新时间。
- 最近 30 天已上传成交的均价、最低~最高成交价、每日成交件数交互图。
- 收藏、最近搜索、深色模式、刷新、分享链接、成交 CSV 导出。
- 手机自适应卡片布局，支持电脑和手机访问。

## 直接部署到 GitHub Pages（推荐）

1. 在 GitHub 创建一个公开仓库，例如 `ff14-market`。
2. 将 **`index.html`、`styles.css`、`app.js`、`favicon.svg`** 上传到仓库根目录。不是只上传 ZIP；请先解压。`README.md` 可一并上传。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择 **main** 分支和 **/(root)**，点击 **Save**。
6. 部署成功后，地址通常类似 `https://你的GitHub用户名.github.io/ff14-market/`。实际网址以 GitHub Pages 给出的链接为准。

这是纯静态网站，不需要购买服务器，不需要填写 API Key。移动端直接打开网址即可使用，也可以添加到手机主屏幕。

## 本地预览

在网站文件目录打开终端：

```bash
python -m http.server 8000
```

随后打开 `http://localhost:8000`。没有安装 Python 也可以用 VS Code 的 Live Server 等本地服务器。

## 数据来源与准确性

- **Universalis 官方公开 API**：`https://universalis.app/api/v2/`，读取各区服当前已上传挂单、历史交易数据和区服列表。不是游戏官方实时数据库。数据由玩家上传，可能延迟、缺失或不完整。
- **XIVAPI 中文镜像**：`https://xivapi-v2.xivcdn.com/`，物品名称、搜索与图标。
- **FFCafe CafeMaker**：`https://cafemaker.wakingsands.com/`，中文搜索和物品资料的备用数据源。
- **公开中文物品名称映射备援**：`https://github.com/dz-knight/ff14-` 仓库中的物品映射 JSON。备用映射是在搜索时从 GitHub 加载，并非完整数据打包在本项目中。

这些公开接口是第三方服务。如果某些网络环境无法访问 API、接口跨域政策改变、服务故障，网站就不能自动获取真实价格。此时会显示错误或空值，**不会显示虚构的模拟价格**。

**重要口径：**

- 最低价、分位数只根据接口当前提供的挂单计算。P25/P50/P75 是按每条挂单单价计算，不是按交易件数加权；极端高价开关仅改变区间图的可视范围，不会篡改真实最低价和分位数。
- 日均成交量 = **近 30 天已上传的成交件数 / 30**，不是该服务器的真实完整销量。交易历史每个大区最多读取最近的 3,000 条；热门物品可能漏掉部分成交，数值是下界性质的参考量。
- 成交均价按交易件数加权；成交历史受玩家上传频率影响。无成交记录和接口失败被区别对待。
- 更新时间来自数据源的相应服务器上传时间；没有服务器级时间时不会据此假装它是最近更新的。
- 如果中文物品搜索服务不可用，可直接输入物品 ID。

## 如何定制

- `styles.css` 中 `:root` 可调整主题色、字体、布局。
- `app.js` 中 `QUICK_ITEMS` 可添加快捷查询物品 ID 和名称（修复版默认留空）。
- 首页默认不选择物品。只有用户搜索或通过 `?item=数字ID` 分享链接打开时才加载行情。
- 搜索 URL 参数包含 `item`、`dc`、`quality`，支持把某个物品的比较链接发给朋友。

## v2 修复记录（2026-10-24）

- 首次打开不预先显示他人截图中的示例物品，也不自动请求其价格；从分享链接 `?item=...` 打开则保留自动查询。
- 搜索时显示进度、候选列表和失败提示；支持物品 ID 直接查价。
- 中文检索使用 XIVAPI 中文镜像、FFCafe 和 GitHub 公共物品名映射三重来源，互为备援。
- 市场接口响应格式必须校验；失败或超时会在页面中清楚提示，不能用假数据或 0 掩饰。
- 本地 HTML 文件在某些手机浏览器 / 文件预览器中存在跨域或网络权限限制，**建议优先部署到 GitHub Pages 的 HTTPS 地址实测**。GitHub Pages 并不保证第三方 API 永远可用。
