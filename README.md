# FF14 市场查价

适用于手机和电脑的 FF14 国服市场行情查询网站。支持物品名称及 ID 搜索、全区/大区切换、NQ/HQ 过滤、各服务器价格比较、近 30 天成交趋势、独立收藏、最多 7 条最近查询、清空查询历史与 CSV 导出。

## 数据来源

- 市场挂单与成交记录：[Universalis](https://universalis.app/) 开放 API
- 物品名称及基础信息：XIVAPI、FFCafe 和公开中文物品名称映射

本站为非官方社区工具。市场数据来自玩家上传，价格和成交记录可能存在延迟或缺失，交易前请以游戏内市场板为准。

## GitHub Pages 部署

1. 将本压缩包解压，确保 `index.html`、`styles.css`、`app.js`、`favicon.svg`、`README.md`、`.nojekyll` 位于仓库根目录。
2. 前往仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**、`main`、`/(root)`，点击 **Save**。
4. 打开 Pages 显示的网址。

## 更新现有网站

在已有的仓库中，替换根目录中的 `index.html`、`styles.css` 和 `app.js`，提交修改即可。其他文件可保留。如果 GitHub 网页上传同名文件提示冲突，请逐个打开文件点右上角铅笔图标编辑、粘贴新版代码，或使用 GitHub Desktop 同步替换。

## 使用说明

- 查询范围默认 **全区**，包含陆行鸟、莫古力、猫小胖、豆豆柴四个大区。
- **常见挂单价区间**：对挂单价格排序后，取大约第 25% 到第 75% 位置的价格，因此包含中间约 50% 的挂单；不是最低到最高价。
- **中位价**：挂单单价排序后位于中间的价格。
- **日均成交**：按最近 30 天已上传的成交数量计算，可能低于实际销量。
- **金币/件**：指每件物品的售价，不是整组物品的总价。

项目为纯静态 HTML/CSS/JS，不需要账号登录、构建步骤或 API 密钥。需要浏览器可以联网访问数据源才能获取行情。

## 本地查询记录

- 最近查询在当前浏览器中保存，最多保留 7 条，重复查询只调整顺序。
- 「清空历史」仅清除最近查询记录，不删除收藏，也不影响当前查询页面。
- 收藏独立保存在当前浏览器；超过 8 项时默认折叠，可点击展开。
- 收藏和查询记录不会在不同浏览器或设备之间自动同步；清理浏览器网站数据会移除本地记录。
